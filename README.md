# 🚀 Featured Projects

## 🤖 Sistem Deteksi Berita Hoaks — IndoBERT & Streamlit

A web-based *hoax news detection system* developed as my undergraduate thesis project.

The system uses *IndoBERT* fine-tuned for Indonesian text classification to classify news articles into *Hoax* and *Non-Hoax* categories.

The trained model is implemented into a web application using *Streamlit*, allowing users to enter news text and receive an automated prediction along with the model's confidence score.

### ✨ Features

* 📰 Indonesian news text classification
* 🤖 IndoBERT-based classification
* 🧹 Text preprocessing
* 🔤 Automatic tokenization
* 📊 Hoax & non-hoax prediction
* 📈 Model confidence score
* 🌐 Streamlit web application
* 📋 Prediction result visualization
* 🔍 Hoax characteristics information

### 🔬 Methodology

* CRISP-DM
* Data Collection
* Data Preprocessing
* Dataset Balancing
* Model Fine-Tuning
* Model Evaluation
* Model Deployment

### 📊 Model Evaluation

The model was evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* ROC Curve
* Precision-Recall Curve
* Learning Curve

The *80:10:10 dataset split* achieved an F1-Score of approximately *0.9944* and was selected for the deployed application based on its consistent evaluation performance.

### 🔧 Technologies

`Python` · `IndoBERT` · `Hugging Face Transformers` · `Pandas` · `NumPy` · `Scikit-learn` · `Streamlit` · `NLP` · `Machine Learning`
